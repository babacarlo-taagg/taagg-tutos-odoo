# CON-03 · Combien coûtent les licences ? — texte de la voix off

## Introduction

1. Bonjour. Avant de chiffrer un projet, ou un an après, au moment du renouvellement, le client demande toujours : combien vont me coûter les licences ? La réponse se lit dans sa base.

2. Le prix d'Odoo Enterprise dépend de deux choses : le nombre d'utilisateurs internes, et le plan. Nous allons trouver les deux, sans rien modifier.

## 1. Compter les utilisateurs internes

3. Dans les paramètres, cherchez Utilisateurs. Odoo affiche le nombre d'utilisateurs actifs.

4. Ouvrons la liste. Le filtre Utilisateurs internes est déjà posé : ce sont les comptes qui travaillent dans Odoo. Chacun compte pour une licence.

## 2. Les comptes qui ne coûtent rien

5. Changeons de filtre : Utilisateurs du portail. Ce sont les clients et les fournisseurs qui consultent leurs devis ou leurs factures en ligne. Ils ne paient pas de licence.

6. Et les utilisateurs inactifs, archivés, ne comptent pas non plus. Un employé parti ou un compte de test : on l'archive, et sa licence disparaît au prochain renouvellement.

## 3. Ce qui impose le plan Custom

7. Deuxième question : le plan. Certaines applications et options imposent le plan Custom, plus cher par utilisateur. D'abord, Studio : dans Applications, cherchons-le.

8. Pas de bouton Activer : Studio est installé. Toute personnalisation Studio fait donc passer la base au plan Custom, pour tous les utilisateurs.

9. Ensuite, le nombre de sociétés. Dans les paramètres, cherchez Sociétés.

10. Deux sociétés. Gérer plusieurs sociétés dans la même base, c'est aussi une option du plan Custom. Si le client n'en a qu'une en réalité, la deuxième doit être archivée.

## 4. Du relevé au chiffrage

11. Vous avez vos deux chiffres : le nombre d'utilisateurs internes et le plan. Relevez le prix du jour sur odoo.com, pour le pays du client, la première année et au renouvellement. Notez la date du relevé.

12. La fiche de cette leçon donne la méthode complète : le coût total sur trois ans, licences, intégration, hébergement et formation compris.

## Les pièges à éviter

13. Trois pièges fréquents. Premier piège : proposer Studio sans dire qu'il change le plan. Le client découvre la différence sur sa facture, et c'est vous qu'il en tient pour responsable.

14. Deuxième piège : oublier les comptes inutiles. Un compte de test ou un employé parti, encore actif, se paie chaque mois.

15. Troisième piège : donner un prix de mémoire. Les tarifs d'Odoo changent avec les versions et selon les pays : relevez-les le jour même, et datez-les.

## Récapitulatif

16. Récapitulons. Le prix dépend des utilisateurs internes et du plan. Les comptes portail et archivés ne coûtent rien. Studio et le multi-sociétés imposent le plan Custom. Et les prix se relèvent le jour même, sur odoo.com.

17. Votre exercice : dans votre base d'essai, comptez les utilisateurs internes, listez ce qui impose le plan Custom, et calculez le coût des licences sur trois ans. Prochaine capsule : suivre la recette dans Projet. À tout de suite !
