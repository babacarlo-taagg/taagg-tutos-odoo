Voix : 3575 caractères.

## Introduction

Bonjour et bienvenue dans cette formation à Studio, l'outil d'Odoo qui permet d'adapter l'application sans écrire de code : ajouter des champs, réorganiser les écrans, automatiser, personnaliser les documents.

Dans cette première capsule, on ne modifie rien. On ouvre Studio et on apprend à lire son écran. À la fin, vous saurez où chercher chaque réglage, au lieu de cliquer au hasard.

Une précision importante : Studio n'existe que dans Odoo Enterprise. Sur Odoo Online, il faut le plan Personnalisé. En version Community, une partie du travail se fait avec le mode développeur.


## 1. Ouvrir Studio

On part d'un écran normal. Ouvrons le devis du mariage de la famille Ndiaye.

Studio s'ouvre avec cette icône, en haut à droite. Elle est présente sur tous les écrans d'Odoo.

L'écran change de couleur. Studio s'est ouvert sur l'écran que vous regardiez : la fiche du devis. C'est la règle d'or de Studio : on personnalise toujours l'écran sur lequel on se trouve.


## 2. Les cinq zones de l'éditeur

Première zone : le menu de Studio, en haut. Vues, Rapports, Automatisations, Contrôle d'accès : chaque entrée est un chantier différent sur le même objet, ici les devis.

Deuxième zone : le canevas, au centre. C'est l'écran lui-même, avec les données du devis. On y clique pour choisir un élément, on y dépose les nouveaux champs.

À gauche, trois onglets. Troisième zone, l'onglet Ajouter : les composants comme les onglets et les colonnes, puis les nouveaux champs, et tout en bas les champs qui existent déjà.

Quatrième zone, l'onglet Vue : les réglages de l'écran entier, par exemple si l'on peut créer ou supprimer un devis depuis cet écran.

Cinquième zone, l'onglet Propriétés. Il s'ouvre dès qu'on clique sur un élément du canevas. Cliquons sur le client.

On retrouve ici tout ce qui concerne ce champ : invisible, requis, lecture seule, son libellé, son infobulle d'aide. Nous nous en servirons dès la prochaine capsule.


## 3. Ce que fabrique Studio

Studio ne modifie jamais le code d'Odoo. Chaque geste ajoute une couche par-dessus le standard. L'entrée Vues, par exemple, montre toutes les façons d'afficher les devis.

Formulaire, liste, kanban, calendrier, graphique… Studio peut modifier chacune séparément.

L'entrée Automatisations rassemble les règles qui agissent toutes seules, par exemple prévenir la cuisine quand un mariage est confirmé. Ici, il n'y en a encore aucune.

Revenons à la fiche du devis.


## 4. Annuler, refaire, fermer

En haut, Annuler et Refaire reviennent sur le dernier geste, tant que vous êtes dans Studio.

Il n'y a pas de bouton Sauvegarder : chaque geste est enregistré tout de suite. Pour sortir, cliquez sur Fermer.


## Les pièges à éviter

Trois pièges fréquents. Premier piège : se tromper d'écran. Ouvert depuis la liste des devis, Studio modifie la liste ; ouvert depuis un devis, il modifie la fiche. Si un champ n'apparaît pas, vérifiez d'abord où vous l'avez mis.

Deuxième piège : tester en direct dans la base du client. Studio est si rapide qu'on est tenté de personnaliser pendant la réunion. Travaillez dans une base de test, puis transférez.

Troisième piège : promettre Studio à un client qui ne l'a pas. Demandez toujours son édition et son abonnement avant de proposer une personnalisation.


## Récapitulatif

Récapitulons. Studio s'ouvre par l'icône en haut à droite, sur l'écran que vous regardez. Cinq zones : le menu de Studio, le canevas, et les onglets Ajouter, Vue et Propriétés. Chaque geste est enregistré aussitôt, et Fermer vous ramène à l'écran normal.

Votre exercice : ouvrez Studio sur la fiche d'un contact, retrouvez les cinq zones, puis fermez sans rien modifier. Dans la prochaine capsule, nous ajouterons nos premiers champs. À tout de suite !
