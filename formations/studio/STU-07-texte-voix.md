# STU-07 · Le devis PDF : l'événement et les convives — texte de la voix off

Brouillon muet : 3 min 58. Voix : 2853 caractères.

## Introduction

Bonjour. Le devis PDF est le visage de l'entreprise face à ses clients. Maïmouna veut y voir le type d'événement et le nombre de convives, pour que le client relise exactement ce qu'il commande.

Dans cette capsule, nous allons voir ce qui se règle sans Studio, puis ajouter ces deux informations au devis PDF avec l'éditeur de rapports.


## 1. Ce qui se règle sans Studio

Le logo, les couleurs, la police et le pied de page avec le NINEA et le registre du commerce ne se règlent pas rapport par rapport. Dans les paramètres, cherchez Mise en page.

Configurer la mise en page du document : un seul réglage, appliqué à tous les documents de la société, devis, factures et bons de livraison. Commencez toujours par là.


## 2. Ouvrir le rapport du devis

Ce qui est propre aux devis, en revanche, se fait dans Studio. Ouvrons le devis du mariage Ndiaye, puis Studio, et le menu Rapports.

Les devis ont plusieurs documents. Celui qu'on imprime et qu'on envoie, c'est Devis / Commande.

L'éditeur montre le modèle du document, avec des données d'exemple. Les zones en pointillés sont calculées par Odoo. Sous les informations du devis, il y a une zone libre, prévue pour ajouter du contenu.


## 3. Insérer les champs

Cliquez dans la zone libre et tapez le texte qui précédera les valeurs.

Pour insérer une valeur du devis, tapez la barre oblique : un menu s'ouvre. Choisissez Champ.

Cherchez Nombre de convives, puis cliquez sur Insérer.

Revenez juste après Événement, et faites de même avec le champ Type d'événement.

Les deux champs sont en place. Ici, contrairement au reste de Studio, il faut enregistrer : cliquez sur Enregistrer.


## 4. Vérifier avec un vrai devis

Cochez Aperçu : le document s'affiche avec un vrai devis. Choisissons celui du mariage Ndiaye.

Sous les informations du devis : Événement, Mariage. Convives, cent cinquante.

Et pour une clause d'acompte réservée aux mariages ? Il faut une condition, qui se pose dans le code du rapport, avec le bouton Modifier les sources. La fiche de cette leçon donne les trois lignes à ajouter.


## Les pièges à éviter

Trois pièges fréquents. Premier piège : refaire le logo et le pied de page dans chaque rapport. La mise en page de la société le fait une fois pour tous.

Deuxième piège : juger le document sur les données d'exemple. Cochez toujours Aperçu, avec un devis où les champs sont remplis, et un autre où ils sont vides.

Troisième piège : oublier qu'on peut revenir en arrière. Le bouton Réinitialiser le rapport efface toutes les personnalisations Studio de ce document, et rend le modèle d'origine.


## Récapitulatif

Récapitulons. Ce qui vaut pour tous les documents se règle dans la mise en page de la société. Ce qui est propre au devis se fait dans Studio, menu Rapports : on tape le texte, la barre oblique, Champ, on insère, on enregistre, et on vérifie avec l'aperçu.

Votre exercice : ajoutez le prix par convive sur la même ligne du devis. Dans la prochaine capsule, nous verrons qui peut voir quoi : les droits d'accès. À tout de suite !
